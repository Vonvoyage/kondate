5回目 — 2026年8月20日（木） 英語メイン · 音声 レッスン05_2026-08-20.m4a

この日の新しい英語 — 相づちとつなぎ言葉

  • That's great! / That sounds fun! — いいね！／楽しそう！
  • Really? / Oh yeah? — へえ、そうなんだ
  • I see. / Got it. — なるほど
  • Well... / Actually... — えーと…／実は…　黙る代わりに使う

新しく分かった文法・語法

  • used to — 昔は〜していた（今はしていない）。I used to run a little.
  • Instead — but を2回続けない。「その代わり」で受ける。Instead, I like walking.
  • I'd recommend — would を入れると柔らかい提案に。I'd like to recommend より自然
  • It's been = It has been
  • Yes, I have. ＋ I went there six years ago. は自然 （経験を答えてから、時期を過去形で足す）

直されたところ

来年日本に来ると聞いて「嬉しい」と言いたい
✗
I happy to hear that.
✓
I'm happy to hear that.
be動詞が抜けています。happy は形容詞なので、I'm が必要。
京都をすすめたい
✗
I'd like to recommend Kyoto.
✓
I'd recommend Kyoto.
意味は通りますが、would だけで柔らかさが出るので like to は不要。
「でも今は走っていない。でも歩くのは好き」
✗
But now I don't run. But I like walking.
✓
But now I don't run at all. Instead, I like walking.
but が2回続くと不自然。2つ目は Instead（その代わり）で受けます。

まとまり英訳（この日から導入）
「言いたいこと」を先に日本語で聞いて、それを英語にする形式。
Oh, that's great. I used to run a little many years ago. But now I don't run at all. Instead, I like walking.
I'm happy to hear that. I'd love to show you around. I'd recommend Kyoto.
「I'd love to show you around.」は一発で自然に出ました。

できたこと　ロールプレイで自分から質問を4つ出せた （Do you like ramen? / Do you know tonkotsu? / Do you go to market every week? など）。 相づちが最初 Mm-hmm だったのを、Oh yeah? / I see. に切り替えられた。 You have to see Kamakura Daibutsu. で have to を自分から使えた。 最後に英語で自己紹介の練習もした。

次への課題　英語パートが長引いて、 フランス語のミニ練習が最後まで届かなかった可能性があります。 英語メインの日は、フランス語を先にやる形も試してみます。

De l'eau の部分を入れ替えれば「〇〇をお願いします」になります （オレンジジュース、コーヒーなど）。この一般化はレッスン中に自力でたどり着きました。

直されたところ

How's the weather these days?
✗
It was cloudy day these days.
✓
It's been cloudy these days.
these days = 今も続いている状態 → 現在完了。It's been = It has been。
Have you ever been to France?
✗
I've been to France six years ago.
✓
I went there six years ago.
現在完了と「◯年前」は一緒に使えません。 現在完了は「いつかは言わない」形なので、時期を言った瞬間に過去形になります。
覚え方：「〜前」「昨日」「去年」が出たら、現在完了は使えない。
私はたいてい家で夕食を食べます
✗
I usually have the dinner at home.
✓
I usually have dinner at home.
一般的な食事（breakfast / lunch / dinner）には冠詞を付けません。
その映画はもう見ました
✗
I watched that movie.
✓
I've already seen that movie.
「もう見た（今も見た状態）」＝現在完了。映画は see / seen のほうが自然。
明日は早く起きなければいけません
✗
Tomorrow I must get up early.
✓
I have to get up early tomorrow.
must＝自分の意思／have to＝状況・外部の理由。 日常会話では have to のほうがずっとよく使われます。

できたこと　長くて聞き取れなかった Vous voulez quelque chose à boire ? を、単語ごとに区切って練習し、 最後は3回連続で言えました。Asseyez-vous も同じく。
ロールプレイのあと、自分からこの2文の追加練習を頼みました。 英語の雑談では、質問を返せるようになっています。

直されたところ

最近ずっと忙しいです
✗
Recently, I'm busy.
✓
I'm busy these days.
「ずっと」は recently より these days / lately のほうが自然。
フランス語を勉強し始めました
✗
I'm just beginning French.
✓
I've just started French.
「始めた」＝過去に起きて今も続いている → 現在完了。
一度もそこへ行ったことがありません
✗
I've never been to there.
✓
I've never been there.
there / here / everywhere / anywhere は副詞なので to を付けない。 この4つは「to を付けないグループ」として覚える。
暑いのが苦手です
✗
I don't like hot.
✓
I don't like the heat.
hot は形容詞。「暑さ」というものを言うので名詞 the heat。
たいてい家にいます
✗
I usually in the home.
✓
I usually stay at home.
動詞が抜けている。stay を入れる。home に the は付けない。

前に覚えた Ça me fait plaisir de vous revoir ! より短くて言いやすい言い方。 Ravie は女性形。男性が言うときは Ravi（発音は同じ）。

この日の新しい英語 — 近況を聞かれたときの3点セット

  • How have you been? — 最近どうしてた？
  • I've been pretty good, just busy with work. — まあまあ元気、仕事が忙しいだけ
  • Nothing much. How about you? — 特に何も。そっちは？

直されたところ

How have you been?
✗
I'm pretty good.
✓
I've been good.
現在完了（have you been）で聞かれたら、答えも I've been で返すと自然。※会話では I'm good. も普通に使う
What have you been up to?
✗
It's nothing special, just the usual.
✓
Not much, just working.
up to は近況ぜんぶを聞いている。仕事だけを聞く How's work going? とは答え方が違う。

できたこと　自分から英語で質問を3つ出せた（Do you know Akasuri? ／ Have you ever been to Okinawa? ／ I'm gonna go to Okinawa.）。 短文3つとも自然。フランス語で aussi（〜も）を教わっていないのに自分で足せた。

直されたところ

What have you been up to?
✓
Not much, just working.
修正なし。テンポも良かった。
How's work going?
✗
It's not special. Usually
✓
It's nothing special, just the usual.
not special → nothing special／usually → just the usual（名詞のかたまりで言い切る）
Are you excited about your trip?
✗
Of course! I love trip
✓
I'm really excited about it.
聞かれたのは「楽しみ？」なので excited で受けて返す。 なお I love trip は I love traveling か I love trips（trip は数えられる名詞）。
